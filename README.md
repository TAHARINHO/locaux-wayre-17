# WAYRE — Deux locaux de bureaux, Paris 17e

Landing page autonome de présentation de deux locaux de bureaux (environ 77 m²) dans le 17e arrondissement de Paris.

## Contenu
- `index.html` — la page (HTML/CSS/JS, aucune dépendance locale hors images).
- `images/` — les visuels et le logo WAYRE.
- `robots.txt` — indexation autorisée.

## Responsive
Testée et ajustée de 320 px à 1440 px :
- 320 px (iPhone SE) — aucun débordement horizontal, titre sur 3 lignes, chiffres du hero sur une ligne.
- 390 px / 430 px — téléphones récents.
- 768 px — tablette portrait.
- 1024 px / 1440 px — ordinateurs.
